# Design mockups

The approved mockups from the design sessions, as HTML fragments. Open one in a browser to view it. Some colors fall back to browser defaults, because these files were shown inside a design-board frame.

| File | What it shows |
|---|---|
| `design-directions.html` | The three original directions. **A, "Terrarium," was chosen.** |
| `a-with-calendar.html` | Direction A: Home, Pet Profile with the feeding calendar, Log a Feeding |
| `husbandry-and-icons.html` | Husbandry screens: profile tiles, sheds, weight, habitat, vet, schedule, regurgitation, poop. Also the first icon ideas. |
| `icons-eye-variations.html` | Variations on the eye icon. **2a, "Scaled Eye," was chosen.** |
| `a-dark-mode.html` | Direction A in dark mode, plus the Settings Appearance switch |
