# RepTender

A free home-screen web app for keeping track of reptile feedings and husbandry: who's due to eat, a monthly feeding calendar, sheds, poop, regurgitation, weight, habitat temps and humidity, care tasks, and vet visits. Built to run on an iPhone through Safari's **Add to Home Screen**, and it works offline with all data stored on the device.

- **Design spec:** [docs/superpowers/specs/2026-11-08-reptender-design.md](docs/superpowers/specs/2026-11-08-reptender-design.md)
- **Approved mockups:** [docs/design/](docs/design/)

## Develop

```bash
npm install
npm run dev        # http://localhost:5173/RepTender/
npm test
```

Pushing to `main` deploys to https://josephsester.github.io/RepTender/.

## Install on iPhone

Open the link above in Safari → Share → **Add to Home Screen**.
